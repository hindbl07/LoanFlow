
# LoanFlow

Digital consumer loan application platform.

## Overview

LoanFlow is a full-stack application that allows prospects
to simulate and apply for consumer loans, clients to track
their applications, and backoffice agents to manage requests.

## Architecture

- Backend: Java 21, Spring Boot
- Frontend: Angular, TypeScript
- Database: PostgreSQL
- Database migrations: Flyway
- Infrastructure: Docker

## Main features

- Loan simulation
- User authentication and authorization
- Online loan application
- Document upload
- Application tracking
- Backoffice application management
